# HR-analytics-PowerBI
Interactive HR Analytics Dashboard built using Power BI

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Project Overview
This dashboard analyzes employee attrition, workforce demographics, job satisfaction, salary distribution, and key HR KPIs.

## KPIs
- Total Employees
- Attrition Rate
- Average Age
- Average Salary
- Department-wise Analysis
- Gender Distribution

- Data Cleaning
- Data Modeling
- DAX
- Dashboard Design
- Business Insights
